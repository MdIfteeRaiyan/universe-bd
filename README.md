# UniVerse BD

UniVerse BD is a responsive university discovery and comparison website for students in Bangladesh. It helps users explore programmes, divisions, districts, budgets, university profiles, costs, and comparison options.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production checks

```bash
npm run lint
npm run build
```

## Deploy on Vercel

Import this GitHub repository into Vercel. Vercel will detect Next.js automatically; no environment variables or custom build settings are required for the current release.
